# What is and is not versioned

Decided 2026-11-01 to keep the repository small and `git status` readable while keeping the documentation value of the plots.

## Tracked
- All code, READMEs, and summary tables (`summary*.md/csv/txt`, `report*.txt/csv`, `decision.md`, `compare_*/`, `post_run*/`).
- Manifests and result records that are small (`manifest*.jsonl`, `results_long.jsonl`, `timing.json`).
- Summary-level plots: any PNG under a `plots/` or `figs/` folder, and `reference/output_style/`.

## Not tracked (ignored, but kept on disk on the laptop and the server)
- Per-run plots, named exactly `run_plot.png`, `global_convergence.png`, `impedance.png`, `placement.png` (about 4000 files, over 400 MB, regenerated by every run).
- Anything under a `logs/` folder and any `*.log`, `*.out`.
- Raw data and large outputs: `Dataset/`, `AllCPU/data_built/`, `GPUAll/out_*/`, `GPUAll/floor_pass/`, `*.mat`, `*.s*p`.

The ignore rules live in `.gitignore` (bottom section). The negations `!**/plots/**`, `!**/figs/**` and `!reference/output_style/**` come after the name rules, so they win.

## Notes
- Ignoring a file does not untrack it: files already committed stay tracked until `git rm --cached` is used. The per-run PNGs were untracked once, in commit "Stop tracking plots and logs" (2026-11-01); they remain on disk.
- When a commit untracks files, a fast-forward on another machine deletes them from that machine's disk. Before moving such a commit to the server, copy the untracked files aside (tar them) and restore afterwards.
- Servers cannot reach GitHub: move commits with `git bundle create x.bundle main ^<old>`, `git fetch x.bundle main`, `git merge --ff-only FETCH_HEAD`.
- Force-push and reset need explicit permission.
- Commit messages: one short line, no trailers, the configured identity.
